# Deep Emerald Enterprise Design System

## Purpose

Define the complete visual and emotional system.

---

## Emotional Tone

Feels like a quiet executive briefing room.
Calm. Precise. Confident.

---

## Color Tokens

Primary:
- Emerald: #15803D
- Hover: #166534
- Active: #14532D
- Soft Tint: #ECFDF5

Neutrals:
- Background: #FFFFFF
- Border: #E5E7EB
- Primary Text: #0F172A
- Secondary Text: #475569

No gradients.
No loud accents.

---

## Typography

Font: Inter

H1: 32px / 600  
H2: 24px / 600  
H3: 18px / 600  
Body: 16px / 400  
Caption: 14px / 400  

Line height: minimum 1.6.

---

## Spacing

8pt grid.

- 4px
- 8px
- 16px
- 24px
- 32px
- 48px

Generous vertical spacing.

---

## Components

Buttons:
- Solid emerald
- 4px radius
- No drop shadow
- 200ms ease transition

Cards:
- 1px border
- 24px padding
- No shadow

Metric callout:
- Large numeric value
- Emerald accent border
- Soft tint background

---

## Micro-Interactions

Minimal fade-in confirmation.

## PDF Styling

- White background
- Strong hierarchy
- Emerald metric emphasis
